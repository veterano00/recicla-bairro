# Recicla Bairro

## Descrição do projeto

O Recicla Bairro é um site educativo sobre separação de resíduos domésticos. Seu objetivo é ajudar moradores a identificar materiais recicláveis, separar resíduos orgânicos e procurar informações sobre a coleta seletiva do município. O projeto se relaciona ao **ODS 12 — Consumo e produção responsáveis**, especialmente à meta 12.5, que trata da redução da geração de resíduos, reciclagem e reúso.

A página principal apresenta orientações para papel, plástico, vidro, metal e resíduos orgânicos, além de passos para começar a separação em casa. As páginas de cadastro e login demonstram a navegação entre formulários e a página principal. Como o projeto foi desenvolvido apenas com HTML e CSS, os formulários não criam contas nem armazenam dados.

## Estrutura do projeto

| Arquivo ou pasta | Conteúdo |
| --- | --- |
| `index.html` | Página principal com guia de separação, orientações e apresentação do ODS 12. |
| `cadastro.html` | Formulário demonstrativo de cadastro com cinco campos obrigatórios. |
| `login.html` | Formulário demonstrativo de login com e-mail e senha. |
| `css/style.css` | Estilos das três páginas. |
| `imagens/` | Ilustrações dos cinco grupos de resíduos. |
| `validacao/` | Resultados e capturas das validações de HTML e CSS. |
| `README.md` | Descrição e estrutura do projeto. |
