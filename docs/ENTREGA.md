# Etapas para concluir a entrega

**Prazo indicado no enunciado:** 18/10/2026, domingo, às 23h59, no horário de Brasília. O envio deve ser feito por um integrante da equipe; neste caso, Vinicius Ortiz Sian.

O código está pronto e as três páginas HTML foram validadas sem erros nem avisos. O CSS foi validado sem erros, com dois alertas leves de cores. A publicação, o print CSS e o vídeo ainda exigem ação.

## 1. Publicar no GitHub

Use um repositório público chamado, por exemplo, `recicla-bairro`. Envie **todos os arquivos e pastas da raiz**, inclusive `index.html`, `css`, `imagens`, `validacao` e `README.md`.

No GitHub, abra **Settings → Pages → Build and deployment**, escolha **Deploy from a branch**, selecione a branch principal (`main`) e a pasta **/(root)**, depois salve. Aguarde o endereço do GitHub Pages aparecer e teste as três páginas, todas as cinco imagens, a fonte e os ícones.

Não publique somente `index.html`; ele precisa de `css/style.css` e das imagens da pasta `imagens`.

## 2. Completar os prints

- Os prints de `index.html`, `cadastro.html` e `login.html` já estão em `validacao/`.
- O CSS foi aceito pelo validador, e sua resposta está preservada em `validacao/css-resultado-w3c.html`.
- Abra `https://jigsaw.w3.org/css-validator/`, valide o CSS publicado por URL (ou use entrada direta), e capture um print com a mensagem **“Não foram encontrados erros”**. Salve-o como `validacao/css-w3c.jpg` e envie ao repositório.
- Se quiser, também revalide o HTML pelas URLs publicadas e substitua os prints por capturas que mostrem os endereços públicos.

## 3. Gravar o vídeo

Use o [roteiro](ROTEIRO-VIDEO.md) como apoio. O vídeo deve durar até 3 minutos e mostrar seu rosto em algum momento. Apresente o nome do projeto, seu nome, objetivo, público-alvo, ODS 12, as três páginas e a estrutura dos arquivos. Teste o link do vídeo em uma janela anônima para confirmar o acesso público.

## 4. Preparar o arquivo de entrega

Copie `entrega-modelo.txt`, preencha os links do **repositório**, do **GitHub Pages** e do **vídeo**, confira os prints e envie o `.txt` no Moodle. Não envie o modelo com `PREENCHER`.

Como o enunciado informa que o trabalho **não será avaliado sem vídeo**, reserve tempo para gravá-lo e testar o acesso ao link.
